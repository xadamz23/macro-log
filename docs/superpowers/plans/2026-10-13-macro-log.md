# Macro Log Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a single-user, mobile-first web app for logging calories/protein/fat/carbs per day against dated targets, with one-tap quick foods, history charts, and an amd64 Docker + Postgres prod deploy.

**Architecture:** FastAPI serves Jinja templates; HTMX swaps fragments (out-of-band updates for bars/entries) and Alpine.js handles small client state (bottom sheet, toggles, calorie autofill, charts). Business logic lives in plain functions under `app/services/` that take a SQLAlchemy `Session` and are unit-tested directly; routes are thin. SQLite in dev, Postgres in prod, schema managed by Alembic.

**Tech Stack:** Python 3.14, uv, FastAPI 0.143, SQLAlchemy 2.1, Alembic 1.20, Jinja2, pydantic-settings, psycopg 3 (binary), PyJWT[crypto], HTMX 2.0.11, Alpine.js 3.17.4, Chart.js 4.5.1, pytest, Docker buildx, Postgres 17.

**Spec:** `docs/superpowers/specs/2026-10-13-macro-log-design.md`

## Global Constraints

- Python `>=3.14`, managed with **uv**; project venv is `.venv/`; run everything via `uv run …`.
- `[tool.uv] package = false` — the `app/` package is imported from the repo root (pytest `pythonpath = ["."]`, Alembic `prepend_sys_path = .`, uvicorn run from `/app`).
- Uvicorn always runs with the factory: `uvicorn --factory app.main:create_app` (no module-level app object).
- Frontend JS is **vendored** into `app/static/vendor/` — no CDN at runtime, no Node build step.
- Macros are always ordered calories, protein, fat, carbs. Calories are integers; protein/fat/carbs are floats rounded to 0.1.
- Calorie autofill formula: `round(4*protein + 4*carbs + 9*fat)`.
- Entries snapshot macros (already multiplied by servings). Editing/deleting a quick food never changes past entries.
- Targets for day D = target row with greatest `effective_date <= D`; if D precedes all rows, use the earliest row; if no rows, no targets. Saving targets upserts the row for *today* only.
- "Today" is computed server-side from the timezone stored in settings (default env `APP_TZ`), midnight boundary.
- All mutations are HTMX requests that swap partials; top-level nav uses `hx-boost`.
- Light + dark mode via CSS custom properties and `prefers-color-scheme`.
- Bottom nav has **five** slots: Today · History · ＋Log (center) · Foods · Settings. (The spec listed four; a fifth "Foods" shortcut to `/settings/foods` keeps the Log button visually centered. Flagged to the user at handoff.)
- No barcode scanning, no external food DB, no CSV export, no backup sidecar, no multi-user.
- Prod images are built for `linux/amd64` via `docker buildx … --push` to `$REGISTRY/macro-log:{git-sha,latest}`.

## Review Focus

1. **Logging just after local midnight** (e.g. 00:30 America/Chicago = 05:30 UTC) must land on the new local day, and 23:30 local must stay on the old one — pinned in Task 4 (`test_today_in_*`).
2. **Saving targets twice in one day** must update that day's row (no unique-constraint crash) and leave earlier days' targets alone — pinned in Task 5 (`test_set_targets_twice_same_day_updates`) and Task 12 (`test_saving_targets_keeps_past_day_targets`).
3. **No targets yet / days before the first target** must render consumed-only with a "set your targets" hint (no division by zero), and older days fall back to the earliest target — pinned in Task 5 and Task 10 (`test_today_without_targets_shows_hint`).
4. **Phone-keyboard input**: blank fields mean 0, comma decimals (`12,5`) are accepted, negatives / non-numbers / `nan` get an inline 422 error and nothing is saved — pinned in Task 9 and Task 11 (`test_create_entry_invalid_returns_422_and_saves_nothing`).
5. **Deleting or editing a quick food that past entries used** must leave those entries' names and macros intact — pinned in Task 7 (`test_delete_quick_food_keeps_entries`) and Task 13 (`test_delete_food_route_keeps_history`).

```python
from pathlib import Path

from sqlalchemy import Engine, create_engine, event
from sqlalchemy.engine import make_url
from sqlalchemy.orm import DeclarativeBase


class Base(DeclarativeBase):
    pass


def make_engine(url: str) -> Engine:
    parsed = make_url(url)
    if parsed.get_backend_name() != "sqlite":
        return create_engine(url, pool_pre_ping=True)

    if parsed.database and parsed.database != ":memory:":
        Path(parsed.database).parent.mkdir(parents=True, exist_ok=True)
    engine = create_engine(url, connect_args={"check_same_thread": False})

    @event.listens_for(engine, "connect")
    def _enable_foreign_keys(dbapi_conn, _record):
        dbapi_conn.execute("PRAGMA foreign_keys=ON")

    return engine
```

```python
from dataclasses import dataclass

MACRO_KEYS = ("calories", "protein", "fat", "carbs")
MACRO_META = {
    "calories": ("Calories", "kcal"),
    "protein": ("Protein", "g"),
    "fat": ("Fat", "g"),
    "carbs": ("Carbs", "g"),
}


def calories_from(protein: float, fat: float, carbs: float) -> int:
    return round(4 * protein + 4 * carbs + 9 * fat)


@dataclass(frozen=True)
class Macros:
    calories: int = 0
    protein: float = 0.0
    fat: float = 0.0
    carbs: float = 0.0

    def __add__(self, other: "Macros") -> "Macros":
        return Macros(
            self.calories + other.calories,
            round(self.protein + other.protein, 1),
            round(self.fat + other.fat, 1),
            round(self.carbs + other.carbs, 1),
        )

    def scaled(self, factor: float) -> "Macros":
        return Macros(
            round(self.calories * factor),
            round(self.protein * factor, 1),
            round(self.fat * factor, 1),
            round(self.carbs * factor, 1),
        )

    def is_zero(self) -> bool:
        return not any((self.calories, self.protein, self.fat, self.carbs))


@dataclass(frozen=True)
class MacroBar:
    key: str
    label: str
    unit: str
    consumed: float
    target: float | None

    @property
    def pct(self) -> float:
        if not self.target:
            return 0.0
        return min(self.consumed / self.target * 100, 100.0)

    @property
    def remaining(self) -> float | None:
        if self.target is None:
            return None
        return round(self.target - self.consumed, 1)

    @property
    def over(self) -> bool:
        return self.target is not None and self.consumed > self.target


def build_bars(consumed: Macros, target: Macros | None) -> list[MacroBar]:
    return [
        MacroBar(
            key,
            *MACRO_META[key],
            consumed=getattr(consumed, key),
            target=None if target is None else getattr(target, key),
        )
        for key in MACRO_KEYS
    ]
```

```python
from datetime import UTC, date, datetime

from sqlalchemy import Date, DateTime, Float, ForeignKey, Integer, String, UniqueConstraint
from sqlalchemy.orm import Mapped, mapped_column

from app.db import Base
from app.services.macros import Macros


class MacroColumns:
    calories: Mapped[int] = mapped_column(Integer, default=0)
    protein: Mapped[float] = mapped_column(Float, default=0.0)
    fat: Mapped[float] = mapped_column(Float, default=0.0)
    carbs: Mapped[float] = mapped_column(Float, default=0.0)

    @property
    def macros(self) -> Macros:
        return Macros(self.calories, self.protein, self.fat, self.carbs)


class AppSettings(Base):
    __tablename__ = "app_settings"

    id: Mapped[int] = mapped_column(primary_key=True)
    timezone: Mapped[str] = mapped_column(String(64))


class Target(MacroColumns, Base):
    __tablename__ = "targets"
    __table_args__ = (UniqueConstraint("effective_date", name="uq_targets_effective_date"),)

    id: Mapped[int] = mapped_column(primary_key=True)
    effective_date: Mapped[date] = mapped_column(Date)
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), default=lambda: datetime.now(UTC)
    )


class QuickFood(MacroColumns, Base):
    __tablename__ = "quick_foods"

    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(100))
    serving_label: Mapped[str] = mapped_column(String(50), default="")
    sort_order: Mapped[int] = mapped_column(Integer, default=0)


class Entry(MacroColumns, Base):
    __tablename__ = "entries"

    id: Mapped[int] = mapped_column(primary_key=True)
    day: Mapped[date] = mapped_column(Date, index=True)
    logged_at: Mapped[datetime] = mapped_column(DateTime(timezone=True))
    name: Mapped[str | None] = mapped_column(String(100))
    servings: Mapped[float] = mapped_column(Float, default=1.0)
    quick_food_id: Mapped[int | None] = mapped_column(
```

`alembic/env.py`:
```python
from logging.config import fileConfig

from alembic import context

import app.models  # noqa: F401  (registers tables on Base.metadata)
from app.config import get_settings
from app.db import Base, make_engine

config = context.config
if config.config_file_name is not None:
    fileConfig(config.config_file_name, disable_existing_loggers=False)

target_metadata = Base.metadata


def _url() -> str:
    return config.get_main_option("sqlalchemy.url") or get_settings().database_url


def run_migrations_offline() -> None:
    context.configure(
        url=_url(), target_metadata=target_metadata, literal_binds=True, render_as_batch=True
    )
    with context.begin_transaction():
        context.run_migrations()


def run_migrations_online() -> None:
    engine = make_engine(_url())
    with engine.connect() as connection:
        context.configure(
            connection=connection,
            target_metadata=target_metadata,
            render_as_batch=connection.dialect.name == "sqlite",
        )
        with context.begin_transaction():
            context.run_migrations()
    engine.dispose()


if context.is_offline_mode():
    run_migrations_offline()
else:
    run_migrations_online()
```

```python
from datetime import UTC, date, datetime
from functools import lru_cache
from zoneinfo import ZoneInfo, available_timezones


def utcnow() -> datetime:
    return datetime.now(UTC)


def as_utc(dt: datetime) -> datetime:
    """SQLite returns naive datetimes; everything we store is UTC."""
    return dt.replace(tzinfo=UTC) if dt.tzinfo is None else dt


def today_in(tz_name: str, now: datetime | None = None) -> date:
    return as_utc(now or utcnow()).astimezone(ZoneInfo(tz_name)).date()


def to_local(dt: datetime, tz_name: str) -> datetime:
    return as_utc(dt).astimezone(ZoneInfo(tz_name))


@lru_cache
def _zones() -> frozenset[str]:
    return frozenset(available_timezones())


def is_valid_timezone(name: str) -> bool:
    return name in _zones()


def timezone_choices() -> list[str]:
    return sorted(_zones())
```

```python
from bisect import bisect_right
from collections.abc import Callable
from datetime import date

from sqlalchemy import select
from sqlalchemy.orm import Session

from app.models import Target
from app.services.macros import Macros


def targets_resolver(db: Session) -> Callable[[date], Macros | None]:
    """Load all target rows once and return a day -> Macros lookup."""
    rows = list(db.scalars(select(Target).order_by(Target.effective_date)))
    dates = [row.effective_date for row in rows]

    def resolve(day: date) -> Macros | None:
        if not rows:
            return None
        index = bisect_right(dates, day) - 1
        return rows[max(index, 0)].macros

    return resolve


def resolve_targets(db: Session, day: date) -> Macros | None:
    return targets_resolver(db)(day)


def set_targets(db: Session, day: date, macros: Macros) -> Target:
    row = db.scalar(select(Target).where(Target.effective_date == day))
    if row is None:
        row = Target(effective_date=day)
        db.add(row)
    row.calories = macros.calories
    row.protein = macros.protein
    row.fat = macros.fat
    row.carbs = macros.carbs
    db.commit()
    return row


def target_history(db: Session) -> list[Target]:
    return list(db.scalars(select(Target).order_by(Target.effective_date.desc())))
```

```python
from datetime import date, datetime

from sqlalchemy import func, select
from sqlalchemy.orm import Session

from app.models import Entry, QuickFood
from app.services.clock import utcnow
from app.services.macros import Macros


def _clean_name(name: str | None) -> str | None:
    return (name or "").strip() or None


def create_entry(
    db: Session,
    *,
    day: date,
    macros: Macros,
    name: str | None = None,
    servings: float = 1.0,
    quick_food_id: int | None = None,
    now: datetime | None = None,
) -> Entry:
    entry = Entry(
        day=day,
        logged_at=now or utcnow(),
        name=_clean_name(name),
        calories=macros.calories,
        protein=macros.protein,
        fat=macros.fat,
        carbs=macros.carbs,
        servings=servings,
        quick_food_id=quick_food_id,
    )
    db.add(entry)
    db.commit()
    return entry


def log_quick_food(db: Session, food: QuickFood, *, day: date, servings: float = 1.0) -> Entry:
    return create_entry(
        db,
        day=day,
        macros=food.macros.scaled(servings),
        name=food.name,
        servings=servings,
        quick_food_id=food.id,
    )


def get_entry(db: Session, entry_id: int) -> Entry | None:
    return db.get(Entry, entry_id)


def list_entries(db: Session, day: date) -> list[Entry]:
    stmt = select(Entry).where(Entry.day == day).order_by(Entry.logged_at, Entry.id)
    return list(db.scalars(stmt))


def day_totals(db: Session, day: date) -> Macros:
    row = db.execute(
        select(
            func.coalesce(func.sum(Entry.calories), 0),
            func.coalesce(func.sum(Entry.protein), 0.0),
            func.coalesce(func.sum(Entry.fat), 0.0),
            func.coalesce(func.sum(Entry.carbs), 0.0),
        ).where(Entry.day == day)
    ).one()
    return Macros(int(row[0]), round(float(row[1]), 1), round(float(row[2]), 1), round(float(row[3]), 1))


def update_entry(db: Session, entry: Entry, *, name: str | None, macros: Macros) -> Entry:
    entry.name = _clean_name(name)
    entry.calories = macros.calories
    entry.protein = macros.protein
    entry.fat = macros.fat
    entry.carbs = macros.carbs
    db.commit()
    return entry


def delete_entry(db: Session, entry: Entry) -> None:
    db.delete(entry)
    db.commit()
```

```python
def list_quick_foods(db: Session) -> list[QuickFood]:
    return list(db.scalars(select(QuickFood).order_by(QuickFood.sort_order, QuickFood.id)))


def get_quick_food(db: Session, food_id: int) -> QuickFood | None:
    return db.get(QuickFood, food_id)


def _apply(food: QuickFood, name: str, serving_label: str, macros: Macros) -> None:
    food.name = name.strip()
    food.serving_label = serving_label.strip()
    food.calories = macros.calories
    food.protein = macros.protein
    food.fat = macros.fat
    food.carbs = macros.carbs


def create_quick_food(db: Session, *, name: str, serving_label: str, macros: Macros) -> QuickFood:
    max_order = db.scalar(select(func.max(QuickFood.sort_order)))
    food = QuickFood(sort_order=(max_order if max_order is not None else -1) + 1)
    _apply(food, name, serving_label, macros)
    db.add(food)
    db.commit()
    return food


def update_quick_food(db: Session, food: QuickFood, *, name: str, serving_label: str, macros: Macros) -> QuickFood:
    _apply(food, name, serving_label, macros)
    db.commit()
    return food


def delete_quick_food(db: Session, food: QuickFood) -> None:
    db.delete(food)
    db.commit()


def move_quick_food(db: Session, food: QuickFood, direction: str) -> None:
    foods = list_quick_foods(db)
    index = next(i for i, f in enumerate(foods) if f.id == food.id)
    target = index - 1 if direction == "up" else index + 1
    if not 0 <= target < len(foods):
        return
    foods[index], foods[target] = foods[target], foods[index]
    for order, item in enumerate(foods):
        item.sort_order = order
    db.commit()


@dataclass(frozen=True)
class RecentFood:
    name: str
    macros: Macros
    count: int


def recent_foods(db: Session, today: date, *, days: int = 30, limit: int = 8) -> list[RecentFood]:
    quick_names = {f.name.strip().lower() for f in list_quick_foods(db)}
    entries = db.scalars(
        select(Entry).where(
            Entry.name.is_not(None),
            Entry.day >= today - timedelta(days=days - 1),
            Entry.day <= today,
        )
    )
    groups: dict[tuple[str, Macros], dict] = {}
    for entry in entries:
        key = (entry.name.strip().lower(), entry.macros)
        if key[0] in quick_names:
            continue
        group = groups.setdefault(key, {"name": entry.name, "count": 0, "last": None})
        group["count"] += 1
        logged = as_utc(entry.logged_at)
        if group["last"] is None or logged > group["last"]:
            group["last"] = logged
    ranked = sorted(groups.items(), key=lambda kv: (kv[1]["count"], kv[1]["last"]), reverse=True)
    return [RecentFood(g["name"], key[1], g["count"]) for key, g in ranked[:limit]]
```

```python
from dataclasses import dataclass
from datetime import date, timedelta
from functools import reduce

from sqlalchemy import func, select
from sqlalchemy.orm import Session

from app.models import Entry
from app.services.macros import MACRO_KEYS, MacroBar, Macros, build_bars
from app.services.targets import targets_resolver


@dataclass(frozen=True)
class DaySummary:
    day: date
    totals: Macros
    targets: Macros | None
    entry_count: int

    @property
    def bars(self) -> list[MacroBar]:
        return build_bars(self.totals, self.targets)


@dataclass(frozen=True)
class Average:
    days_logged: int
    totals: Macros
    targets: Macros | None


def _summaries(db: Session, *conditions, limit: int | None = None) -> list[DaySummary]:
    stmt = (
        select(
            Entry.day,
            func.sum(Entry.calories),
            func.sum(Entry.protein),
            func.sum(Entry.fat),
            func.sum(Entry.carbs),
            func.count(Entry.id),
        )
        .where(*conditions)
        .group_by(Entry.day)
        .order_by(Entry.day.desc())
    )
    if limit:
        stmt = stmt.limit(limit)
    resolve = targets_resolver(db)
    return [
        DaySummary(
            day=day,
            totals=Macros(int(cal), round(float(p), 1), round(float(f), 1), round(float(c), 1)),
            targets=resolve(day),
            entry_count=count,
        )
        for day, cal, p, f, c, count in db.execute(stmt)
    ]


def logged_days(db: Session, *, before: date | None = None, limit: int = 20) -> list[DaySummary]:
    conditions = [Entry.day < before] if before else []
    return _summaries(db, *conditions, limit=limit)


def _mean(items: list[Macros]) -> Macros:
    return reduce(lambda a, b: a + b, items, Macros()).scaled(1 / len(items))


def average(db: Session, today: date, days: int) -> Average | None:
    summaries = _summaries(db, Entry.day >= today - timedelta(days=days), Entry.day < today)
    if not summaries:
        return None
    targets = [s.targets for s in summaries if s.targets is not None]
    return Average(
        days_logged=len(summaries),
        totals=_mean([s.totals for s in summaries]),
        targets=_mean(targets) if targets else None,
    )


def chart_series(db: Session, today: date, days: int) -> dict:
    start = today - timedelta(days=days - 1)
    by_day = {s.day: s for s in _summaries(db, Entry.day >= start, Entry.day <= today)}
    resolve = targets_resolver(db)
    labels: list[str] = []
    series: dict[str, list] = {key: [] for key in MACRO_KEYS}
    targets: dict[str, list] = {key: [] for key in MACRO_KEYS}
    for offset in range(days):
        day = start + timedelta(days=offset)
        labels.append(day.isoformat())
        summary = by_day.get(day)
        target = resolve(day)
        for key in MACRO_KEYS:
            series[key].append(getattr(summary.totals, key) if summary else None)
            targets[key].append(getattr(target, key) if target else None)
    return {"labels": labels, "series": series, "targets": targets}
```

```python
import math
from collections.abc import Mapping
from dataclasses import dataclass
from typing import Any

from app.services.macros import MACRO_KEYS, Macros, calories_from

GRAM_MAX = 2000
CALORIE_MAX = 20000
GRAM_KEYS = ("protein", "fat", "carbs")


def fmt_num(value: float | int | None) -> str:
    if value is None:
        return "–"
    rounded = round(float(value), 1)
    return str(int(rounded)) if rounded.is_integer() else f"{rounded:.1f}"


def form_values(macros: Macros) -> dict[str, str]:
    return {key: fmt_num(getattr(macros, key)) for key in MACRO_KEYS}


@dataclass
class MacroForm:
    values: dict[str, str]
    errors: dict[str, str]
    macros: Macros | None

    @property
    def ok(self) -> bool:
        return not self.errors


def _number(raw: str, maximum: float) -> float | None:
    """Parse a user-typed number. Blank -> None. Raises ValueError with a message."""
    if raw == "":
        return None
    try:
        value = float(raw.replace(",", "."))
    except ValueError:
        raise ValueError("Must be a number") from None
    if not math.isfinite(value):
        raise ValueError("Must be a number")
    if value < 0 or value > maximum:
        raise ValueError(f"Must be between 0 and {maximum}")
    return value


def parse_macro_form(data: Mapping[str, Any]) -> MacroForm:
    values = {key: str(data.get(key) or "").strip() for key in MACRO_KEYS}
    errors: dict[str, str] = {}
    grams: dict[str, float] = {}
    for key in GRAM_KEYS:
        try:
            grams[key] = round(_number(values[key], GRAM_MAX) or 0.0, 1)
        except ValueError as exc:
            errors[key] = str(exc)
    calories: int | None = None
    try:
        raw_calories = _number(values["calories"], CALORIE_MAX)
        calories = None if raw_calories is None else round(raw_calories)
    except ValueError as exc:
        errors["calories"] = str(exc)
    if errors:
        return MacroForm(values, errors, None)

    if calories is None:
        calories = calories_from(grams["protein"], grams["fat"], grams["carbs"])
    macros = Macros(calories, grams["protein"], grams["fat"], grams["carbs"])
    if macros.is_zero():
        return MacroForm(values, {"form": "Enter at least one value"}, None)
    return MacroForm(values, {}, macros)


def parse_text(data: Mapping[str, Any], key: str, *, max_len: int, required: bool = False) -> tuple[str, str | None]:
    value = str(data.get(key) or "").strip()
    if required and not value:
        return value, "Required"
    if len(value) > max_len:
        return value, f"Max {max_len} characters"
    return value, None


def parse_servings(raw: str | None) -> float:
    if raw is None or str(raw).strip() == "":
        return 1.0
    value = float(str(raw).replace(",", "."))
    if not math.isfinite(value) or value <= 0 or value > 20:
        raise ValueError("Servings must be between 0 and 20")
    return value
```

```js
// Global UI glue: HTMX error toasts and the Alpine components used by the templates.

function showToast(message, isError) {
  const slot = document.getElementById("toast");
  if (!slot) return;
  const el = document.createElement("div");
  el.className = "toast" + (isError ? " error" : "");
  el.textContent = message;
  slot.replaceChildren(el);
  setTimeout(() => el.remove(), 4000);
}

document.addEventListener("htmx:responseError", (event) => {
  showToast(`Something went wrong (${event.detail.xhr.status})`, true);
});
document.addEventListener("htmx:sendError", () => {
  showToast("Network error, check your connection", true);
});

document.addEventListener("alpine:init", () => {
  // Calories follow 4P + 4C + 9F until the user types their own number.
  Alpine.data("macroForm", () => ({
    caloriesTouched: false,
    init() {
      const value = this.field("calories").value;
      this.caloriesTouched = value !== "" && Number(value) !== this.computed();
    },
    field(name) {
      return this.$root.querySelector(`[name=${name}]`);
    },
    num(name) {
      const value = parseFloat((this.field(name).value || "0").replace(",", "."));
      return Number.isFinite(value) ? value : 0;
    },
    computed() {
      return Math.round(4 * this.num("protein") + 4 * this.num("carbs") + 9 * this.num("fat"));
    },
    autofill() {
      if (this.caloriesTouched) return;
      const calories = this.computed();
      this.field("calories").value = calories ? calories : "";
    },
  }));

  // Bottom sheet; its body is (re)loaded from the server every time it opens.
  Alpine.data("logSheet", (autoOpen) => ({
    open: false,
    init() {
      if (autoOpen) this.$nextTick(() => this.show());
    },
    show() {
      this.open = true;
      htmx.trigger(this.$refs.body, "load-sheet");
    },
    hide() {
      this.open = false;
    },
  }));

  // Chart instances live outside Alpine's reactive proxy (Chart.js breaks when proxied).
  Alpine.data("historyCharts", (initialDays) => {
    let charts = [];
    return {
      days: initialDays,
      init() {
        this.load();
      },
      destroy() {
        charts.forEach((chart) => chart.destroy());
        charts = [];
      },
      setRange(days) {
        this.days = days;
        this.load();
      },
      async load() {
        const response = await fetch(`/history/data?days=${this.days}`);
        if (!response.ok) {
          showToast("Couldn't load charts", true);
          return;
        }
        this.render(await response.json());
      },
      render(data) {
        this.destroy();
        const css = getComputedStyle(document.documentElement);
        const color = (name) => css.getPropertyValue(name).trim();
        Chart.defaults.color = color("--muted");
        Chart.defaults.borderColor = color("--border");
        const labels = data.labels.map((iso) => iso.slice(5));
        const base = {
          responsive: true,
          maintainAspectRatio: false,
          interaction: { mode: "index", intersect: false },
        };
        const legend = { labels: { boxWidth: 12, filter: (item) => !item.text.endsWith("target") } };
        const targetLine = (label, values, lineColor) => ({
          type: "line", label, data: values, borderColor: lineColor, borderDash: [6, 4],
          borderWidth: 1.5, pointRadius: 0, stepped: true, spanGaps: true,
        });
        charts = [
          new Chart(this.$refs.calories, {
            type: "bar",
            data: {
              labels,
              datasets: [
                { type: "bar", label: "Calories", data: data.series.calories, backgroundColor: color("--cal"), borderRadius: 4 },
                targetLine("Calories target", data.targets.calories, color("--muted")),
              ],
            },
            options: { ...base, plugins: { legend } },
          }),
          new Chart(this.$refs.macros, {
            type: "line",
            data: {
              labels,
              datasets: ["protein", "fat", "carbs"].flatMap((key) => [
                {
                  label: key[0].toUpperCase() + key.slice(1), data: data.series[key],
                  borderColor: color(`--${key}`), backgroundColor: color(`--${key}`),
                  tension: 0.25, pointRadius: 2, spanGaps: false,
                },
                targetLine(`${key} target`, data.targets[key], color(`--${key}`)),
              ]),
            },
            options: { ...base, plugins: { legend } },
```

```python
from datetime import date

from fastapi import APIRouter, HTTPException, Request
from fastapi.responses import HTMLResponse

from app.deps import DB, TZ, Today
from app.forms import form_values, parse_macro_form, parse_servings, parse_text
from app.services.entries import create_entry, delete_entry, get_entry, log_quick_food, update_entry
from app.services.foods import create_quick_food, get_quick_food, list_quick_foods, recent_foods
from app.templating import templates
from app.views import day_context

router = APIRouter()


def _parse_day(raw, today: date) -> date:
    try:
        day = date.fromisoformat(str(raw or ""))
    except ValueError:
        return today
    return min(day, today)


def _refresh(request: Request, db, day: date, today: date, tz: str, *, toast_entry=None, headers=None):
    context = {**day_context(db, day, today), "tz": tz, "oob": True, "toast_entry": toast_entry}
    return templates.TemplateResponse(request, "partials/day_refresh.html", context, headers=headers)


def _entry_or_404(db, entry_id: int):
    entry = get_entry(db, entry_id)
    if entry is None:
        raise HTTPException(status_code=404, detail="Entry not found")
    return entry


@router.get("/log-sheet", response_class=HTMLResponse)
def log_sheet(request: Request, db: DB, today: Today, day: str = ""):
    context = {
        "day": _parse_day(day, today),
        "quick_foods": list_quick_foods(db),
        "recent": recent_foods(db, today),
        "values": {},
        "errors": {},
        "prefix": "entry",
    }
    return templates.TemplateResponse(request, "partials/log_sheet.html", context)


@router.post("/entries", response_class=HTMLResponse)
async def create_entry_route(request: Request, db: DB, tz: TZ, today: Today):
    data = await request.form()
    day = _parse_day(data.get("day"), today)
    form = parse_macro_form(data)
    name, name_error = parse_text(data, "name", max_len=100)
    serving_label, label_error = parse_text(data, "serving_label", max_len=50)
    save_quick = data.get("save_quick") == "on"

    errors = dict(form.errors)
    if name_error:
        errors["name"] = name_error
    if label_error:
        errors["serving_label"] = label_error
    if save_quick and not name:
        errors["name"] = "Name is required to save as a quick food"
    if errors:
        context = {
            "day": day,
            "values": {**form.values, "name": name, "serving_label": serving_label, "save_quick": save_quick},
            "errors": errors,
            "prefix": "entry",
        }
        return templates.TemplateResponse(
            request, "partials/entry_form.html", context, status_code=422,
            headers={"HX-Retarget": "#entry-form", "HX-Reswap": "outerHTML"},
        )

    quick_food_id = None
    if save_quick:
        quick_food_id = create_quick_food(db, name=name, serving_label=serving_label, macros=form.macros).id
    entry = create_entry(db, day=day, macros=form.macros, name=name, quick_food_id=quick_food_id)
    return _refresh(request, db, day, today, tz, toast_entry=entry, headers={"HX-Trigger": "entry-logged"})


@router.post("/quick-foods/{food_id}/log", response_class=HTMLResponse)
async def log_quick_food_route(food_id: int, request: Request, db: DB, tz: TZ, today: Today):
    data = await request.form()
    food = get_quick_food(db, food_id)
    if food is None:
        raise HTTPException(status_code=404, detail="Quick food not found")
    try:
        servings = parse_servings(data.get("servings"))
    except ValueError:
        raise HTTPException(status_code=422, detail="Invalid servings") from None
    day = _parse_day(data.get("day"), today)
    entry = log_quick_food(db, food, day=day, servings=servings)
    return _refresh(request, db, day, today, tz, toast_entry=entry, headers={"HX-Trigger": "entry-logged"})


@router.get("/entries/{entry_id}/edit", response_class=HTMLResponse)
def edit_entry_form(entry_id: int, request: Request, db: DB):
    entry = _entry_or_404(db, entry_id)
    context = {"entry": entry, "values": {**form_values(entry.macros), "name": entry.name or ""}, "errors": {}}
    return templates.TemplateResponse(request, "partials/entry_edit.html", context)


@router.get("/entries/{entry_id}/row", response_class=HTMLResponse)
def entry_row(entry_id: int, request: Request, db: DB, tz: TZ):
    entry = _entry_or_404(db, entry_id)
    return templates.TemplateResponse(request, "partials/entry_row.html", {"entry": entry, "tz": tz})


@router.put("/entries/{entry_id}", response_class=HTMLResponse)
async def update_entry_route(entry_id: int, request: Request, db: DB, tz: TZ, today: Today):
    entry = _entry_or_404(db, entry_id)
    data = await request.form()
    form = parse_macro_form(data)
    name, name_error = parse_text(data, "name", max_len=100)
    errors = dict(form.errors)
    if name_error:
        errors["name"] = name_error
    if errors:
        context = {"entry": entry, "values": {**form.values, "name": name}, "errors": errors}
        return templates.TemplateResponse(
            request, "partials/entry_edit.html", context, status_code=422,
            headers={"HX-Retarget": f"#entry-{entry.id}", "HX-Reswap": "outerHTML"},
        )
    update_entry(db, entry, name=name, macros=form.macros)
    return _refresh(request, db, entry.day, today, tz)


@router.delete("/entries/{entry_id}", response_class=HTMLResponse)
def delete_entry_route(entry_id: int, request: Request, db: DB, tz: TZ, today: Today):
    entry = _entry_or_404(db, entry_id)
    day = entry.day
    delete_entry(db, entry)
    return _refresh(request, db, day, today, tz)
```

```python
def _targets_context(db, today: date, *, values=None, errors=None, saved=False) -> dict:
    if values is None:
        current = resolve_targets(db, today)
        values = form_values(current) if current else {}
    return {
        "values": values,
        "errors": errors or {},
        "saved": saved,
        "history": target_history(db),
        "today": today,
        "prefix": "target",
    }


def _tz_context(tz: str, today: date, *, error=None, saved=False) -> dict:
    return {"timezone": tz, "timezones": timezone_choices(), "today": today, "error": error, "saved": saved}

        "nav": "settings",

        "tzctx": _tz_context(tz, today),
    }

async def save_targets(request: Request, db: DB, today: Today):

    if not form.ok:
        context = _targets_context(db, today, values=form.values, errors=form.errors)
        return templates.TemplateResponse(request, "partials/targets_card.html", context, status_code=422)
    set_targets(db, today, form.macros)
    return templates.TemplateResponse(request, "partials/targets_card.html", _targets_context(db, today, saved=True))


@router.post("/settings/timezone", response_class=HTMLResponse)
async def save_timezone(request: Request, db: DB, tz: TZ, today: Today):
    name = str((await request.form()).get("timezone") or "")

        set_timezone(db, name)
    except ValueError as exc:
        context = _tz_context(tz, today, error=str(exc))
        return templates.TemplateResponse(request, "partials/timezone_card.html", context, status_code=422)

    return templates.TemplateResponse(request, "partials/timezone_card.html", context)
```

```python
def _food_or_404(db, food_id: int):
    food = get_quick_food(db, food_id)
    if food is None:
        raise HTTPException(status_code=404, detail="Quick food not found")
    return food


def _parse(data) -> tuple[dict, dict, object]:
    form = parse_macro_form(data)
    name, name_error = parse_text(data, "name", max_len=100, required=True)
    label, label_error = parse_text(data, "serving_label", max_len=50)
    errors = dict(form.errors)
    if name_error:
        errors["name"] = name_error
    if label_error:
        errors["serving_label"] = label_error
    return {**form.values, "name": name, "serving_label": label}, errors, form.macros


def _list(request: Request, db, *, oob: bool = False, status_code: int = 200):
    return templates.TemplateResponse(
        request, "partials/food_list.html", {"foods": list_quick_foods(db), "oob": oob}, status_code=status_code
    )

    return templates.TemplateResponse(request, "foods.html", context)

def food_list(request: Request, db: DB):
    return _list(request, db)

    values, errors, macros = _parse(await request.form())
    if errors:
        context = {"values": values, "errors": errors, "prefix": "add"}
        return templates.TemplateResponse(request, "partials/food_add.html", context, status_code=422)
    create_quick_food(db, name=values["name"], serving_label=values["serving_label"], macros=macros)
    context = {"values": {}, "errors": {}, "prefix": "add", "foods": list_quick_foods(db), "oob": True, "with_list": True}
    return templates.TemplateResponse(request, "partials/food_add.html", context)

        raise HTTPException(status_code=422, detail="direction must be up or down")
```

```python
"""Defence in depth behind Cloudflare Access: reject requests that didn't come through Access."""

import jwt
from fastapi import FastAPI
from starlette.concurrency import run_in_threadpool
from starlette.requests import Request
from starlette.responses import PlainTextResponse

EXEMPT_PATHS = {"/healthz"}


class AccessVerifier:
    def __init__(self, team_domain: str, audience: str, jwks_client=None):
        self.issuer = f"https://{team_domain}"
        self.audience = audience
        self.jwks_client = jwks_client or jwt.PyJWKClient(
            f"{self.issuer}/cdn-cgi/access/certs", cache_keys=True, lifespan=3600
        )

    def verify(self, token: str) -> dict:
        signing_key = self.jwks_client.get_signing_key_from_jwt(token)
        return jwt.decode(
            token, signing_key.key, algorithms=["RS256"], audience=self.audience, issuer=self.issuer
        )


def install_access_check(app: FastAPI, verifier: AccessVerifier) -> None:
    @app.middleware("http")
    async def access_check(request: Request, call_next):
        if request.url.path in EXEMPT_PATHS:
            return await call_next(request)
        token = request.headers.get("cf-access-jwt-assertion") or request.cookies.get("CF_Authorization")
        if not token:
            return PlainTextResponse("Forbidden", status_code=403)
        try:
            await run_in_threadpool(verifier.verify, token)
        except jwt.PyJWTError:
            return PlainTextResponse("Forbidden", status_code=403)
        return await call_next(request)
```

```python
"""Generate PWA icons (three macro bars on green) with no image dependencies.

Run: uv run python scripts/make_icons.py
"""

import struct
import zlib
from pathlib import Path

OUT = Path(__file__).resolve().parent.parent / "app" / "static" / "icons"
BG = (47, 111, 78)
TRACK = (36, 88, 61)
BARS = [((217, 119, 6), 0.80), ((96, 165, 250), 0.60), ((52, 211, 153), 0.45)]


def _png(size: int, rows: list[bytes]) -> bytes:
    def chunk(tag: bytes, data: bytes) -> bytes:
        return struct.pack(">I", len(data)) + tag + data + struct.pack(">I", zlib.crc32(tag + data) & 0xFFFFFFFF)

    raw = b"".join(b"\x00" + row for row in rows)
    header = struct.pack(">IIBBBBB", size, size, 8, 2, 0, 0, 0)
    return b"\x89PNG\r\n\x1a\n" + chunk(b"IHDR", header) + chunk(b"IDAT", zlib.compress(raw, 9)) + chunk(b"IEND", b"")


def draw(size: int) -> bytes:
    pixels = [[BG] * size for _ in range(size)]
    margin, bar_h, gap = size * 0.2, size * 0.11, size * 0.07
    top = (size - (3 * bar_h + 2 * gap)) / 2
    x0, x1 = int(margin), int(size - margin)
    for i, (color, fraction) in enumerate(BARS):
        y0 = int(top + i * (bar_h + gap))
        filled_to = int(x0 + (x1 - x0) * fraction)
        for y in range(y0, int(y0 + bar_h)):
            for x in range(x0, x1):
                pixels[y][x] = color if x < filled_to else TRACK
    rows = [bytes(channel for pixel in row for channel in pixel) for row in pixels]
    return _png(size, rows)


if __name__ == "__main__":
    OUT.mkdir(parents=True, exist_ok=True)
    for name, size in [("icon-192.png", 192), ("icon-512.png", 512), ("apple-touch-icon.png", 180)]:
        (OUT / name).write_bytes(draw(size))
        print(f"wrote {OUT / name}")
```

```js
// Network-first cache for static assets only; pages and API calls always go to the network.
const CACHE = "macro-log-v1";
const SHELL = [
  "/static/css/app.css",
  "/static/js/app.js",
  "/static/vendor/htmx.min.js",
  "/static/vendor/alpine.min.js",
  "/static/vendor/chart.umd.js",
  "/static/icons/icon-192.png",
];

self.addEventListener("install", (event) => {
  event.waitUntil(caches.open(CACHE).then((cache) => cache.addAll(SHELL)));
  self.skipWaiting();
});

self.addEventListener("activate", (event) => {
  event.waitUntil(
    caches.keys().then((keys) => Promise.all(keys.filter((key) => key !== CACHE).map((key) => caches.delete(key)))),
  );
  self.clients.claim();
});

self.addEventListener("fetch", (event) => {
  const url = new URL(event.request.url);
  if (event.request.method !== "GET" || !url.pathname.startsWith("/static/")) return;
  event.respondWith(
    fetch(event.request)
      .then((response) => {
        if (response.ok) {
          const copy = response.clone();
          caches.open(CACHE).then((cache) => cache.put(event.request, copy));
        }
        return response;
      })
      .catch(() => caches.match(event.request)),
  );
});
```
